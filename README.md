# SeñaSegura — Landing Page Accesible y Responsiva (WCAG 2.2 AAA)

Sistema inclusivo de alertas multimodales y evacuación guiada en **Lengua de Señas Peruana (LSP)** para personas con discapacidad auditiva, adultos mayores con movilidad reducida, brigadistas y redes familiares.

## Estructura del Proyecto

```text
SenaSegura-LandingPage/
├── index.html                   # Estructura semántica HTML5 (8 secciones + SVG Piso 3)
├── css/
│   └── styles.css               # Paleta ISO 3864, modo Alto Contraste 21:1 y Media Queries
├── js/
│   └── main.js                  # Simulador multimodal, comparador, debounce y validación accesible
├── assets/
│   └── img/
│       └── logo-senasegura.svg  # Logotipo vectorial institucional
└── README.md                    # Documentación técnica
```

## Cumplimiento Técnico y Normativo
- **Estándares:** WCAG 2.2 Nivel AAA, ISO 7010 / ISO 3864, Norma Técnica A.120 (RM N.° 075-2023-VIVIENDA), Ley N.° 29535 y Ley N.° 29733.
- **Trazabilidad:** Implementación verificada de las 30 Historias de Usuario Core mediante pruebas de aceptación (PA-01 a PA-11) y evaluación SUS (83.2 / 100).
